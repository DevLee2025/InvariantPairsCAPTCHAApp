# VLM Simulation & Benchmark Suite for GRIT

This directory contains the decoupled **Vision-Language Model (VLM)** evaluation and benchmark suite for crowd-sourcing invariant image pairs to feed the **GRIT** (Geometric Robustness via Invariant Training) method.

---

## 📁 Layout & Scripts

```
vlm_eval/
  rng.py                      # Deterministic mulberry32 PRNG + round generator
  vlm_model.py                # OpenCLIP zero-shot & VLM evaluation model backends
  fast_vlm_simulator.py       # High-speed direct batch dataset generator
  browser_vlm_agent.py        # Playwright headed browser agent (visual UI play)
  verify_grit_compatibility.py# GRIT SVD subspace estimation & precision verifier
  out/                        # Saved game records, Parquet outputs, and reports
```

## 🚀 Execution Guide

### 1. Fast Direct Batch Simulation
Run 20 dev puzzles directly without launching a browser:
```bash
python vlm_eval/fast_vlm_simulator.py --rounds 20 --seed 1337 --backend clip
```

### 2. Live Headed Browser Agent Play (Watch VLM Play Web UI)
Start the Vite dev server (`cd web && npm run dev`), then launch the Playwright agent:
```bash
python vlm_eval/browser_vlm_agent.py --rounds 10 --seed 1337 --backend clip
```

### 3. Verify GRIT Compatibility & Build Parquet Dataset
```bash
python vlm_eval/verify_grit_compatibility.py vlm_eval/out/grit-game-vlm-clip-dev.json
```
